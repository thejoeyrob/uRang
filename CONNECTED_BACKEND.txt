Reverse identity:
The deployed function already contains IPQS support. It becomes active automatically
once an Edge Function secret named IPQS_API_KEY is added in Supabase.

No API key is stored in the PWA or this repository.

Important:
The current Supabase function is hosted as a separate Edge Function in the user's
existing Supabase project. It does not read or write any Danco database tables.
A dedicated uRang Supabase project can be created later if desired.
